# TechStore - Cổng Thanh Toán & Hóa Đơn Điện Tử

Dự án trang thanh toán chuyển khoản VietQR và xuất hóa đơn điện tử cho sản phẩm **Samsung Galaxy S25+ 5G (12GB / 256GB)**.

## 🌐 Trực tuyến (Live Demo - GitHub Pages)
- **Trang thanh toán:** [https://dtgkhang.github.io/s25-plus-payment/](https://dtgkhang.github.io/s25-plus-payment/)
- **Trang hóa đơn:** [https://dtgkhang.github.io/s25-plus-payment/hoa-don.html](https://dtgkhang.github.io/s25-plus-payment/hoa-don.html)

## 📱 Tính năng chính
- Giao diện chuẩn mobile-first, thanh thoát, không viền màu rực rỡ hay hiệu ứng thừa.
- Header tĩnh (`position: static`), cuộn tự nhiên cùng nội dung trang.
- Tích hợp chuẩn mã VietQR Ngân hàng số Techcombank.
- Nút sao chép STK / Số tiền thông minh kèm phản hồi tại chỗ (`✓ Đã chép`).
- Thời gian ghi nhận hóa đơn tự động lưu timestamp thực tế lúc xác nhận giao dịch.
- Hỗ trợ in phiếu thu trực tiếp bằng lệnh in trình duyệt (`window.print()`).
